# jobrun

Durable job queue on Postgres: gRPC control plane + in-process worker pool + cron scheduler + reaper +
`/admin` SSE page in one binary (`jobrund`), with a `jobrun` CLI. Design record: `docs/PLAN.md` (ADR-0001);
read it before touching a port or a signature - they are frozen there.
Module `github.com/crowbett/jobrun`, Go 1.27. Global Go conventions from `~/.claude/CLAUDE.md` apply.

## Layout
- `proto/jobrun/v1/jobrun.proto` - JobService + ScheduleService (WorkerService reserved in comments). `buf lint` + `buf breaking`.
- `gen/jobrun/v1/` - GENERATED by `task gen`, COMMITTED, never hand-edited (hookify blocks writes; CI diffs `buf generate`).
- `internal/job/` - DOMAIN, no I/O, imports nothing internal: Job/Status/Policy/Cursor/Event/Schedule, sentinels,
  `Store`/`Dispatcher`/`Handler`/`TxHandler` ports, `Registry`, validation.
- `internal/cronx/` - 5-field cron parser + `Next(after)` in a named tz (DST gap skips, repeat fires once). No deps.
- `internal/postgres/` - the ONLY package with SQL: pool, goose migrations (embedded), `Store` (job.Store), `Notifier`
  (LISTEN/NOTIFY + poll floor), `AdvisoryLocker`, `sqlc/` (GENERATED from `db/query/*.sql`, never hand-edited).
- `internal/worker/` - Pool: claim loop per queue -> bounded handlers -> Complete/Fail; heartbeater with fencing.
- `internal/scheduler/`, `internal/reaper/` - leader-elected cron materialiser; expired-lease sweeper + retention purge.
- `internal/server/` - gRPC adapters (validate, convert, map errors to codes) + bufconn table tests.
- `internal/admin/` - Broker, SSE, `/admin/stats`, `/metrics` text exposer, depth cache, histogram; `web/admin.html` embedded.
- `internal/obs/` - OTel providers, slog trace ids, span helpers, `Snapshot` counters. `internal/config/` - env `Load()`/`Validate()`.
- `internal/handlers/` - built-in `noop`, `sleep`, `fail`, `echo`. `internal/interceptor/` - Recover -> RequestID -> Logging.
- `cmd/jobrund/main.go` - wiring only + the six-stage teardown. `cmd/jobrun/` - CLI (`main.go`, `jobs.go`, `schedule.go`, `bench.go`).

## Commands (Taskfile.yml)
- `task db:up` (postgres:17 on 5434) | `task run` (migrates, gRPC :50052, admin 127.0.0.1:9110, `WORKER_QUEUES=default,bench`)
- `task build` (bin/jobrund, bin/jobrun) | `task client -- enqueue --type sleep --payload '{"ms":200}'` | `task admin`
- `task bench` (`jobrun bench --rate 200 --duration 60s`; `-- --direct` for the COPY path, needs `DATABASE_URL`)
- `task gen` | `task sqlc` | `task migrate` | `task lint` (buf + golangci-lint) | `task lint:breaking` | `task fmt`
- `task test` (`-race`, needs gcc) | `task test:fast` | `task test:integration` (`-tags integration`, `TEST_DATABASE_URL`) | `task check`

## Conventions specific to this repo
- Ports are frozen: pg 5434, gRPC :50052, admin 127.0.0.1:9110 (orders has 5433/4223, sysmon 9100, aigw 8090).
- Schema first: edit `proto/` -> `task gen`; edit `internal/postgres/migrations` + `db/query` -> `task sqlc`. Never edit generated dirs.
- The clock rule: every comparison and default uses the database clock (`now()` or `Store.Now`), never `time.Now`,
  for `run_at`, leases, `finished_at`, purge age. `jobrund` warns at startup when the skew exceeds 2 s.
- Every mutating store method is exactly one transaction, opened only inside `internal/postgres` (`withTx`).
  A handler's `Commit` closure is "writes only, no network" and runs under a 5 s `statement_timeout`.
- Never publish events or notify from handlers: transitions are published by the pool/reaper after the store commits,
  and `pg_notify` runs inside the enqueue transaction so a consumer can never wake before the row is visible.
- Handlers: return `fmt.Errorf("%w: ...", job.ErrPermanent)` to skip retries; honour `ctx` (it is cancelled on lost
  lease, cancel request, `JOB_TIMEOUT` and drain). Implement `job.TxHandler` for exactly-once effects.
- Errors leave gRPC handlers as `status.Error(codes.X, ...)`: InvalidArgument, NotFound, FailedPrecondition, AlreadyExists, Internal.
- Metrics come from one `obs.Snapshot`; `/metrics` text and the OTel instruments must read the same values. Queue depth is cached (5 s), never scanned per scrape.
- Unit tests use the in-memory fakes; anything that needs Postgres goes behind `//go:build integration` and `TEST_DATABASE_URL`.
- `cmd/jobrund` embeds `time/tzdata` so IANA schedule timezones resolve on Windows and distroless.
- On Windows, the stop signal is Ctrl-Break; the six `teardown N/6` lines must appear in order and the process exits 0.

## Definition of done
`go build ./...`, `go vet ./...`, `golangci-lint run ./...`, `go test -race -count=1 ./...` (or `task test:fast` without a
C compiler - say which), `TEST_DATABASE_URL=... go test -race -count=1 -tags integration ./internal/postgres/...` with the
stack up, `buf lint`, and `buf generate` leaving `git status --porcelain gen/` empty. `/go-test` and `/go-lint` run the Go side.
